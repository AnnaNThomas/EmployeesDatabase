# Employees Database Management System

## Project Overview
A database management application developed using C# Windows Forms and Microsoft SQL Server.

## Technologies Used
- C#
- .NET Windows Forms
- Microsoft SQL Server
- SQL


## Features
- Employee data management
- Database connectivity
- Insert, update, delete and retrieve employee records

## Database
Microsoft SQL Server is used to store and manage employee information.

## Project Structure
- `EmployeesDatabase/` – C# application source code
- `Database/` – SQL database creation scripts

## How to Run
1. Clone this repository.
2. Open the solution file in Visual Studio.
3. Execute the SQL script to create the database.
4. Configure the SQL Server connection string.
5. Run the Windows Forms application.
